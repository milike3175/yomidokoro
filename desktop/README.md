# よみどころ デスクトップ版（試し版）

`app/` の公開用の書き出し（`app/out`、TECHO=0）を、ダブルクリックで開けるアプリにしたもの。Electron で作っている。

- 画面は `yomi://app/` というアプリの中だけの住所で開く。ネットの口（ポート）は開かないので、ほかのパソコンからは接続できない
- 県のサイトや手引きの PDF へのリンクは、アプリの中では開かず、いつものブラウザで開く
- Claude の API は呼ばない。鍵も使わない
- 様式に書いた値・事業者の控えは、このパソコンの中だけで扱う。どこにも送らない
- 手帳（自分専用の電話の記録）は入っていない。入れる仕組みもまだ無い

## 開き方

### Windows
zip は二つある。どちらを使うかは、Windows の「設定」の「システム」の「バージョン情報」にある「システムの種類」で決める。

- 「ARM ベース プロセッサ」と書いてある（Mac の Parallels の Windows など）：`yomidokoro-0.0.6-win-arm64.zip`
- 「x64 ベース プロセッサ」と書いてある（ふつうの Windows 機）：`yomidokoro-0.0.6-win-x64.zip`

**Mac と共有している場所では開けません。** `C:\Mac\...`、`\\Mac\...`、`\\psf\...` の場所や、
Windows のデスクトップ・ドキュメントが Mac とつながっている場合（Parallels の「Mac とフォルダを共有」が入っているとき）、
ネットワークの場所（`\\` で始まる場所、ネットワークドライブ）では、開こうとしても閉じてしまいます。
必ず `C:\yomidokoro` などの Windows の中のフォルダに zip を写して、そこで展開してください。
（この場所から開いたときは「この場所からは開けません」という案内が出て終わります）

1. エクスプローラーで `C:\` を開き、新しいフォルダ `yomidokoro` を作る。zip をそこに写し、右クリックして「すべて展開」
2. 展開したフォルダ（`C:\yomidokoro\...`）の中の `yomidokoro.exe` をダブルクリック
3. 青い画面「Windows によって PC が保護されました」が出たら、「詳細情報」を押し、「実行」を押す
   （署名をしていないアプリなので出る。一度実行すれば、次からは出ない）

zip のまま中の exe を開くと動かない。必ず展開してから開く。

開かずに閉じたときは、起動の記録 `%APPDATA%\yomidokoro\launch-log.txt` を作った人に送る
（エクスプローラーの住所の欄に `%APPDATA%\yomidokoro` と打つと開く）。
記録に書くのはアプリの動き（起動・窓・読み込み・落ちた理由）だけで、様式に書いた値や事業者の控えは書かない。
Mac では `~/Library/Application Support/yomidokoro/launch-log.txt`。

### Mac（Apple のチップの Mac）
1. `yomidokoro-0.0.6-arm64-mac.zip` をダブルクリックして展開し、`yomidokoro.app` を「アプリケーション」に移す
2. ダブルクリックすると「開いていません」「Apple は検証できませんでした」と出る。「完了」で閉じる
3. 「システム設定」の「プライバシーとセキュリティ」を開き、下の方の「yomidokoro がブロックされました」の横の「このまま開く」を押す。もう一度確認が出たら「開く」
   （古い macOS では、アプリを右クリックして「開く」でもよい）

## 様式を取ってくる

上の「ファイル」の献立から「和歌山県の様式第六号（新規）を県のサイトから取ってくる」を選ぶ。
取ってきた様式は、利用者フォルダの `様式/30/` に置かれ、sha256（ファイルの指紋）が `_記録.json` に残る。

- Windows：`%APPDATA%\yomidokoro\様式\`
- Mac：`~/Library/Application Support/yomidokoro/様式/`

県のサイトが断ったときは「手で取ってきてください」と出る。県のページを開いて自分で保存し、「様式に書く」画面に置けば使える。

### 道具が取ってこられない県（愛知県など。11/6 昼から）

愛知県のサイトは、アプリからの自動の取得を受け付けない。その県は、画面の県の行と「様式を手で置く」に「様式ファイルを保存する」のリンクが出る。押すと、いつものブラウザがダウンロードのフォルダに様式を落とす。
そのあと「作成」を押せば、アプリがダウンロードのフォルダとデスクトップ（いちばん上だけ）を見て、道具の知っている様式（対応表の sha256 と同じ中身）だけを見つけて使う。「様式を手で置く」の「ダウンロードのフォルダから様式を探す」でも同じ。
見つけた様式と、手で置いた様式は、利用者フォルダの `様式/<県コード>/` に写して覚える。次に開いたときも置かれている。
中身が対応表と違うファイルは写さず、名前も画面に出さない。zip や古い形（.doc・.xls）を置いたときは、その理由を画面に出す。

## 作る人向け

```
cd app && npm run build          # TECHO=0 の公開用の書き出し（app/ の側）
cd ../desktop && npm install
npm start                        # app/out を _写し/ に写して開く
npm run 様式を試す                # 和歌山の様式を一回だけ取ってきて結果を出す
npm run 書き出し:win              # Windows の持ち運び版（zip、署名なし、x64 と arm64 の二つ）
npm run 書き出し:mac              # Mac 版（zip、署名なし）
```

`scripts/copy-out.mjs` は、`app/out` に手帳の帯（TECHO=1 の印）や、様式・手引きの本体（docx・xlsx・pdf など）があれば写さずに止める。例外は `app/data/公開する様式.yaml` に sha256 で許したもの（今は和歌山県の様式第六号だけ）。ファイル名ではなく中身の sha256 で見る。
書き出したもの（zip・exe・app）と `_写し/` は git に入れない（`.gitignore`）。

画面（`_写し/site`）と記入の対応表（`_写し/様式`）は app.asar の中に入れる。日本語のフォルダ名が asar の外に出ると、Windows の zip の展開で崩れることがあるため。
Windows では GPU を使わない（`app.disableHardwareAcceleration()`。Parallels などの仮想の画面で落ちるのを避ける）。
Windows で exe の場所が Mac との共有（`C:\Mac\`・`\\Mac\`・`\\psf\`）やネットワークの場所なら、窓を作らずに案内を出して終える。
Chromium のサンドボックスがその上では動かず、画面の処理が launch-failed（アクセス拒否）で落ちるため。サンドボックスは切らない（`--no-sandbox` は使わない）。
最初の画面が出る前にページの処理が launch-failed で二回落ちたとき、GPU などの処理が二回落ちたときも、同じ案内を出して終える。

## 事業者の控え（0.0.5 から）

アプリでは、控えをブラウザのダウンロードではなく、よみどころ専用の置き場に保存する。読み込むときは、その置き場の一覧から選ぶ。

- Windows：`%APPDATA%\yomidokoro\控え`
- Mac：`~/Library/Application Support/yomidokoro/控え`

同じ名前があるときは上書きせず、`_2`、`_3` を付けて別に残す。置き場は「ファイル」の献立の「事業者の控えの置き場を開く」か、画面の「置き場を開く」で開ける。ほかの場所に置いた控え（ブラウザ版で保存したものなど）は「ほかの場所のファイルから読み込む」で読める。

## 申請書の下書き（0.0.6 から）

上の帯の「事業者さんの名簿」→「新しい事業者さんを入れる」で、事業者さんの情報と品目を一度入れ、申請する県に印を付けて（いくつでも。地方ごとにまとまっている）「作成」を押すと、県ごとに下書きができる。事業者さんは名簿に残り、次はそこから開ける。

今書ける県（11/5 夜の版から）：
- 和歌山県：申請書（Word。事業計画の概要の文、第10面と別紙4の誓約書の住所・名称・代表者も。車両の前面・側面と容器の写真を画面で選ぶと、第6面・第7面に貼る。1台目の車両と容器2つまで。写真は PNG か JPEG）
- 山形県：申請書と、別紙「事業計画の概要を記載した書類」（Word。全体計画・品目ごとの運搬量と性状・排出事業場・運搬先・車両・容器・具体的な計画・環境保全措置の文）
- 奈良県：申請書（Excel）
- 京都府（11/6 夜の版から）：申請書（作成代理人用の様式。行政書士の事務所の住所・名前・電話番号の欄が出る）と事業計画の概要（Word）。品目は府の記入例の形：①燃え殻　②汚泥 … の札と、様式に印刷された「（ 含む ・ 除く ）」の当てはまる方に○（Word の囲い文字）、「以上 N 種類」。概要は全体計画の一文、品目の表（含むときだけ「（石綿含有産業廃棄物）」の括弧書き）、車両の表（呼び方つき）、容器の表、具体的な計画（営業日・収集運搬計画・車両ごとの用途）、環境保全措置、写真、誓約書。府のサイトから道具が取ってこられる
- 愛知県：申請書と事業計画の概要（Word。品目は県の記載例の形：名前の後ろに印（＊※■▲）、「以上○品目（水銀使用製品産業廃棄物を含む。）」、印の説明。概要は、品目の表（印つきの名前、運搬量・性状・排出事業場・運搬先、いちばん下の行に印の説明）と、記載例の型の文（全体計画は品目ごと、具体的な計画は車両ごと＋時間＋休業日＋印の説明、環境保全措置 (1)(2)(3)）、事務所、誓約書・申立書の申請者。第2面の運搬車両一覧・運搬容器と従業員数の内訳はまだ書かない。県のサイトが自動の取得を断るので、「様式ファイルを保存する」で落としてから「作成」）

- 様式は「作成」のときに県のサイトから取ってくる。取れないときは、手で取ってきたファイルを画面のいちばん下「様式を手で置く」に置けば使える
- 取ってきた様式は sha256 で記入の対応表と照らし、一致したものにだけ書く。県が様式を改めていたら書かない
- 下書きの置き場は 書類（Documents）の `よみどころ_下書き`。ファイル名は `県名_様式名_下書き_日付`。同じ名前があれば上書きせず `_2` を付ける
- 置き場は「ファイル」の献立の「申請書の下書きの置き場を開く」か、画面の「下書きの置き場を開く」で開ける
- 書いた値はネットに送らない。アプリの記録（ログ）にも書かない
