# 電話メモ（取り込みの手順）

分担：この Skill は「取り込みの手順」。中身を整える決まり（個人名を消す・観点を選ぶ・聞き返しは一問まで）は、ミオ（`.claude/agents/mio.md`）と指示文（`app/prompts/mio.md`）が持つ。手順で迷ったらここ、中身で迷ったらミオの決まりに従う。

目標は「話す（貼る）→ 1回だけ答える → 地図に載る」。みゆきの手数を増やさない。

## 1. 入口を選ぶ

みゆきの言い方から、次のどれかを選ぶ。聞かずに分かるときは聞かない。

| 入口 | こういうとき | 実行（`app/` で） |
|---|---|---|
| 音声入力（superwhisper の録音） | 「いま話した」「録音した」「電話メモ」だけ | `npm run 取込` |
| 貼り付け | 文字をチャットに貼った・「コピーした」 | チャットの文なら `npm run 取込 -- 標準入力`（文を渡す）。クリップボードなら `npm run 取込 -- 貼付` |
| ファイル | メモのファイルを指定した | `npm run 取込 -- ファイル <パス>` |
| Notion の議事録 | 議事録の URL を渡した | 下の「議事録のとき」 |

議事録から取り込むときは `--取込元 議事録` を付ける。

### 議事録のとき

- `notion-fetch` で読む。`include_transcript` は付けない。使うのは要約（summary）とメモ（notes）だけ。文字起こし・ページの題名・置き場所は使わない
- 依頼者の会社名・所在地・人名・案件の固有の事情を消した文にしてから、`npm run 取込 -- 標準入力 --取込元 議事録` に渡す
- 日付が議事録の中に無いときは、議事録ページの最終更新の月（YYYY-MM）を使う。渡す文の先頭に「日付：YYYY-MM（議事録の更新月。実際に聞いたのはこれ以前）」の一行を足す（取込は話に出た日付を確認日にするので、何もしないと今日の日付になる）
  - 見せる段階で、答えに「（確認日は議事録の更新月。実際に聞いたのはこれ以前）」の注記が無ければ、保存後にその記録の各答えの末尾へ書き足し、`npm run 確認` を通す

## 2. 整えた結果を見せて、確認をもらう

- まず `--保存` を付けずに実行する。Claude から動かすと端末が無いので、結果を見せて「保存していない」で止まる
- 出てきた要約（許可権者・種別・窓口・日付・観点・答え）を、そのままみゆきに見せる。言い換えない
- 聞き返し（「聞き返し：〜」）が出たら、その一問だけをみゆきに聞き、答えを `--答え "<答え>"` で渡して実行し直す。こちらから二問目は聞かない
- みゆきが「保存して」と言ったら、同じ入口に `--保存` を付けて実行する。整え直しで中身が変わることがあるので、二回目の結果が一回目と違えば、保存したものを見せて「これで良いか」をもう一度確かめる
  - 手数を減らしたいときは、みゆき自身に端末で `! cd app && npm run 取込 -- 貼付` を打ってもらう方法もある（Enter で保存できる）

## 3. 共有する記録に残さないもの、手元だけに残すもの（2026-11-06 みゆき）

一件の記録は二つに分かれる。**共有する記録**（窓口・回答・指摘。公開版や見本に出してよい形）と、**手元だけ**の欄（`手元だけ: { 担当者, 案件, メモ }`。自分のパソコンの中にだけ残り、公開版・見本・GitHub には出ない）。

- 共有する記録には、役所の担当者の名前を残さない（「担当者」と書く。日付と課名だけ）。依頼者の会社名・人名も残さない（「依頼者」と書く）
- 手元だけの欄には、担当者の名前と、どの案件の電話か（依頼者の会社名・手続き・事情）を残してよい。取込が埋める。手で書き足してもよい
- 住所（番地まで）・生年月日・本籍・車両番号・電話番号は、誰のものでも、どの欄にも残さない（名簿と記入は手元のプログラムだけ）
- 議事録の URL・Notion のページ名（`取込元: 議事録` とだけ残す）
- 取込の検査（三段）に引っかかって保存されなかったときは、文を直して入れ直す。検査を外す方法を探さない。検査は、共有する部分には人名・会社名・住所・車両番号、手元だけの欄には住所・車両番号を見る

## 4. 疑わしい記述

- 話していない・書いていないことは補わない
- 聞き違い・言い間違いが疑わしい答え、窓口が「たぶん」「担当によって」と言った答えは、入れないか、答えの末尾に「（次の電話で確かめる）」と付けて入れる。どちらにするかはみゆきに一言で聞く
- 既存の記録と食い違いそうなら、取込が「食い違いの候補」と出す。どちらが正しいかは決めない（地図に「揺れあり、要確認」と出る）

## 5. 保存のあと

- `npm run 確認` を通す（書き方の決まりに合っているか）。誤りが出たら、ファイル名・行番号を見て直す
- みゆきへの報告は3行以内：記録した件の要約（許可権者・種別・観点・答え）、共有する記録から外した名前の件数と止めた情報の件数、手元だけに残した担当者と案件
- 手帳（`手帳/`）は GitHub に上げない。保存先は手帳の中だけで、`app/` には何も書かない
